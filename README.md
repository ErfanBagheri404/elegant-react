# Elegant

Fashion-store landing page with a minimal editorial layout: full-bleed hero,
collection strip, product grids and a newsletter block. Design-to-code rebuild of
a Dribbble/Behance concept.

**Live:** https://elegantclone.netlify.app/

## Stack

React - Vite - Tailwind - react-icons.

## Run

```bash
git clone https://github.com/ErfanBagheri404/elegant-react.git
cd elegant-react
```

```bash
npm install
npm run dev
```

`npm run build` writes `dist/`; the site is static. Imagery is in `src/assets/`.
